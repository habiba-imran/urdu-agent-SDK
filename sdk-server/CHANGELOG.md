## [0.1.1] - Unreleased

### Added
- MIT license metadata and complete terms included in the npm package.
- Optional `signatureVersion: 'raw-body-v1'` for exact UTF-8 request-body signing
  after the portal's versioned verifier has been deployed. The default remains
  `canonical-json-v1` for compatibility with older portals.
- Wire-body contract tests for exponent-form floats and Unicode, and protection
  against overriding the signature-version header through extra headers.

### Fixed
- Send the same canonical JSON string that was signed, rather than serializing
  the request a second time. Explicit nulls retain their place in the signed body.

### Release status
- Prepared for release under MIT; npm publishing configuration remains required.
- No provider, model, voice or browser SDK changes.

## [0.1.0]

First public npm release of `@awaazlabs-uva/agents`.

- Initial package: `createAgent`, `listAgents`, `updateAgent`, `getProviderCapabilities`,
  managed-number listing and agent assignment.
- Test suite (`npm test`, Node's built-in test runner). Request signing is checked against a
  vector generated by the tenant portal's own verifier (`tenant_portal_api/machine_auth.py`),
  including Urdu-script bodies (audit §2 item 26).
- `CHANGELOG.md` is shipped in the npm package.
- Package metadata now points at `Finova-Solutions/urdu-voice-agent-SDK`.
