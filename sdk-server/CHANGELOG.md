# Changelog — @awaazlabs-uva/agents

All notable changes to the server-side agent-management SDK. Format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/); versions follow
[Semantic Versioning](https://semver.org/).

Releases are cut by pushing an `agents-v<version>` tag that matches `version` in `package.json`
(see `.github/workflows/release-sdk.yml`). Add an entry here in the same PR that bumps the version.

## [Unreleased]

### Added
- Test suite (`npm test`, Node's built-in test runner). Request signing is checked against a
  vector generated by the tenant portal's own verifier (`tenant_portal_api/machine_auth.py`),
  including Urdu-script bodies (audit §2 item 26).
- `CHANGELOG.md` is shipped in the npm package.
- Package metadata now points at `Finova-Solutions/urdu-voice-agent-SDK`.

## [0.1.0]

- Initial package: `createAgent`, `listAgents`, `updateAgent`, `getProviderCapabilities`,
  managed-number listing and agent assignment. Not yet published to npm.
